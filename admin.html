🔑 How to get your GitHub Token in 30 seconds (Click to expand)
  1. Open GitHub Token Generator in a new tab.
  2. Set Expiration to No expiration (or 90 days).
  3. Ensure the repo scope checkbox is checked.
  4. Scroll to the bottom and click green "Generate token".
  5. Copy the token (starts with ghp_) and paste it into the box above, then click "Save GitHub Settings"!
